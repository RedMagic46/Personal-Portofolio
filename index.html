Halo! Saya Naufal Muammar, mahasiswa program studi S1 Teknik Informatika di Universitas Muhammadiyah Malang yang saat ini sedang menempuh perkuliahan Semester 5.

Perjalanan saya dalam dunia rekayasa perangkat lunak dimulai dari ketertarikan mengeksplorasi logika komputasi dan mentransformasikannya menjadi produk nyata yang solutif. Saya terbiasa membangun antarmuka web yang rapi, cepat, dan responsif menggunakan ekosistem TypeScript dan React/Next.js, serta mendalami fondasi backend, database, dan pemrograman mobile.

Selain fokus perkuliahan, saya aktif mengeksplorasi dan membagikan repositori open-source di GitHub (RedMagic46), mulai dari sistem inventory, pendeteksi kesehatan mental berbasis web, hingga perancangan simulasi grafika komputer.
